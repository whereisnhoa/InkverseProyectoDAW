# 📚 Proyecto "Inkverse"

Un espacio para leer, crear y compartir historias.

Inkverse es una plataforma web desarrollada como proyecto del ciclo formativo superior de Desarrollo de Aplicaciones Web (DAW). Su objetivo es crear una comunidad digital en la que los usuarios puedan descubrir obras literarias, compartir sus propias creaciones, publicar ilustraciones e interactuar con otros usuarios.

La plataforma reúne diferentes espacios relacionados con la literatura, el arte y la creatividad en un mismo entorno.

# Características principales

👤 Gestión de usuarios: registro, inicio de sesión y cierre de sesión.

📝 Gestión de perfiles: visualización y edición de información personal y avatar.

📖 Publicación de obras: posibilidad de crear y compartir contenido literario.

📚 Lectura de obras: acceso a publicaciones de otros usuarios.

❤️ Sistema de favoritos: guardar obras de interés.

💬 Comentarios: interacción entre lectores y autores.

🎨 Galería de arte: espacio para compartir y descubrir ilustraciones.

🌐 Sistema multidioma: soporte para distintos idiomas.

🗣️ Foros: espacio de participación e intercambio de ideas entre usuarios.
